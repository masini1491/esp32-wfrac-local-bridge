## 2. Mapping to actual project behavior

- [`ITransport::perform`](../../components/wfrac_transport/include/wfrac_transport/transport.hpp): synchronous one-physical-attempt interface with borrowed request/response storage, no cancellation token, no async state. `TransportRequest.timeout_ms` is a **single transport timeout setting**, not evidence of hard `D_total`.
- [`EspHttpTransport::perform`](../../components/wfrac_transport_espidf/src/esp_http_transport.cpp): stack-local `ResponseCollector` passed in ESP HTTP event `user_data`, fresh client, synchronous `esp_http_client_perform`, then `esp_http_client_cleanup`; callback storage must not be released by supervisor merely because deadline elapsed.
- [`execute_api_request`](../../components/wfrac_client/src/request_executor.cpp): one physical attempt, optional **second** HTTP compatibility fallback if a distinct external scheme policy decision explicitly says so. D2 compile harness must not mistake compile of one physical attempt for full logical-operation bound.
- [`RuntimeOrchestrator::step`](../../components/wfrac_client/include/wfrac_client/runtime_orchestrator.hpp): deadline checked before/after synchronous transport; not preemptive. Existing orchestration semantics must not be rewritten as a hard deadline.
